# ⚛️ React Projects Collection

A comprehensive collection of React applications showcasing various concepts, state management patterns, and modern web development practices.

## 📚 Projects Overview

### 1. 🧮 [Calculator](./calculator)
A modern, fully functional calculator with basic arithmetic operations.
- **Tech Stack**: React, CSS3
- **Features**: Basic operations, decimal support, keyboard input, responsive design
- **Run**: `cd calculator && npm start`

### 2. 🛒 [E-Commerce Store](./ecommerce)
Feature-rich shopping application with cart management and product search.
- **Tech Stack**: React, Redux Toolkit, Bootstrap 5
- **Features**: Product catalog, search, shopping cart, discounts, stock tracking
- **Run**: `cd ecommerce && npm start`

### 3. 📄 [Resume Builder](./my-resume-app)
Professional resume builder with form-based input and instant preview.
- **Tech Stack**: React, Vite, Redux Toolkit, Tailwind CSS
- **Features**: Multiple sections, form validation, print/download, modern UI
- **Run**: `cd my-resume-app && npm run dev`

### 4. ✅ [Todo App with Redux](./react_todo_app_redux)
Full-featured todo list with Redux state management.
- **Tech Stack**: React, Redux Toolkit, Bootstrap
- **Features**: CRUD operations, task editing, completion tracking
- **Run**: `cd react_todo_app_redux && npm start`

### 5. 📝 [Todo List - Task Manager](./todolist)
Beautiful task manager with two-column layout and modern gradients.
- **Tech Stack**: React, Bootstrap, CSS3
- **Features**: Active/completed columns, status badges, smooth animations
- **Run**: `cd todolist && npm start`

## 🚀 Quick Start

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Running Any Project

```bash
# Navigate to the project folder
cd <project-name>

# Install dependencies
npm install

# Start the development server
npm start        # For Create React App projects
# OR
npm run dev      # For Vite projects (my-resume-app)
```
